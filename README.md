# Lista de Algoritmos em C

Uma coleção de algoritmos fundamentais implementados em linguagem C, desenvolvida com foco educacional para o aprendizado e prática de estruturas de dados e lógica de programação.

## 📋 Sobre o Projeto

Este repositório contém uma compilação de exercícios algorítmicos organizados em 4 listas progressivas, totalizando entre 48 e 80 exercícios. O projeto foi desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas na FATEC - Rubens Lara, com o objetivo de consolidar conhecimentos fundamentais de programação.

### Pré-requisitos

- Compilador C (recomendado: Code::Blocks)
- Conhecimentos básicos de programação em C

Cada lista possui complexidade crescente, permitindo uma progressão natural no aprendizado.

## ⚠️ Observações Importantes

- **Compilador**: O código foi otimizado para Code::Blocks. Outros compiladores podem apresentar incompatibilidades menores
- **Convenção de Nomenclatura**: Variáveis incluem números correspondentes ao exercício para evitar conflitos
- **Documentação**: Cada algoritmo possui o enunciado completo comentado no início do código

## English Version

# C Algorithms Collection

A comprehensive collection of fundamental algorithms implemented in C language, designed with educational focus for learning and practicing data structures and programming logic.

## 📋 About the Project

This repository contains a compilation of algorithmic exercises organized into 4 progressive lists, totaling between 48 and 80 exercises. The project was developed during the Systems Analysis and Development course at FATEC - Rubens Lara, aiming to consolidate fundamental programming knowledge.

### Prerequisites

- C Compiler (recommended: Code::Blocks)
- Basic knowledge of C programming

## ⚠️ Important Notes

- **Compiler**: Code optimized for Code::Blocks. Other compilers may present minor incompatibilities
- **Naming Convention**: Variables include numbers corresponding to their exercise to avoid conflicts
- **Documentation**: Each algorithm has complete problem statement commented at the beginning
